# The sidebar edits a stereotype in the class diagram alone

- **Observed:** G-20 asks that the sidebar edit every property the notation shows. The UML
  example's sidebar edits a stereotype, the word in guillemets above a name, only for a classifier
  of the class diagram. A state, an action, a use case, or an actor shows none and the sidebar
  offers none, though UML 2.5.1 lets any named element carry one. The whole-branch review of
  uml-diagrams found it on 2026-11-20, and the human counted G-20 as met with it open.
- **Where:** the forms of `examples/uml/src/sidebar.ts`, the node content each diagram module of
  `examples/uml/src/` builds, and the descriptor that names a kind's form.
